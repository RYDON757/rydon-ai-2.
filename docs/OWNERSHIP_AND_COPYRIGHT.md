## What this record does
This is a project-maintenance record for keeping the app's name, website, repository, and displayed copyright notice together. Git history, dated commits, deployment records, and original source files can help document development history. Keep copies of these records.

## Important legal distinction
A notice in the app is not the same as an official copyright registration, company registration, or trademark registration. Before submitting a government or institutional form, enter the actual legal name of the person or entity that owns the work, the correct creation/publication dates, and the requested work description. Do not claim registration or ownership of third-party components unless you have the rights to do so.

## Suggested short description for a form
“RYDON AI 2.0 is a browser-based AI assistant application with a web interface and server-side application code, supporting chat, browser voice features, text/PDF document extraction, optional web search, and browser-local chat history and memory.”

## Evidence to preserve
- Dated Git commits and pull requests in the source repository.
- Copies of original source files and release versions.
- Render deployment history and the public website URL.
- Records identifying any collaborators and the work they contributed.
- Licences and notices for third-party dependencies and assets.

## Privacy and security
Never include API keys, passwords, session secrets, user chat contents, or private customer information in public ownership documents.
